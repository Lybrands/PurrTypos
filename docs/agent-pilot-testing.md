# Agent 真实试运行协议

本协议用于第八阶段。它不是自动化测试：你使用自己的模型配置运行案例，再以人工判断评审真实结果。

## 运行原则

1. 在一本书内开启 Agent 工具；每次只运行一个案例并保留该轮的 `run_id`。P1 虽开启工具，仍应不发生工具调用。
2. 不要在同一次运行中混入额外需求，否则结果无法比较。
3. P4 必须使用可安全删除的测试人物，并在批准卡上选择“拒绝”。
4. 每次结束后先查看运行是否完成、是否超出上下文预算、是否发生越权工具调用；再按五维 rubric 评分。

## 建议顺序

按 P1、P2、P3、P4、P5 的顺序运行。P1 是基线，P2 测上下文，P3 测只读边界，P4 测人类确认，P5 测多步执行。

## 每个案例记录的最小信息

- 案例 ID 与 `run_id`
- 模型名、上下文窗口和是否开启 Agent 工具
- 结果状态：done / failed / blocked
- 五维评分：grounding、task_completion、actionability、calibration、writing_fit（各 0–4）
- 一条最重要的观察：成功原因或失败现象

请不要提交 API Key、完整私人正文或敏感设定；向协作者报告案例 ID、run_id、评分和脱敏现象即可。

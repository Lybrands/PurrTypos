# 小说分析校验链路统一

## 实现

- 分批保存与最终提交共用 bind_model_candidate_scope：模型位置字段先移除，提取阶段使用宿主片段绑定，汇总阶段从冻结上游证据恢复。保留来源章节检查。
- 汇总范围恢复容忍空白差异，文字和标点仍须匹配。
- 最终提交工具内校验全部证据；无效证据以明确条目路径返回 tool_input_invalid，未写入，可让模型修正。不再静默删除单条证据后保留整个结论。
- 后续最终校验也遵循上述严格完整性要求；不能静默降级已提交结果。
- 技法原文复用、读取位置预算、invalid_entry 等模型可修正错误归入输入错误。权限、冻结引用、版本冲突不改为输入错误；未分类 ValueError 不再伪装成引用错误，保留工具执行失败。

## 验证

四组相关测试共 126 个独立用例通过（原 125 项回归，以及追加最终提交修正测试；追加后来源对话组 29 项全部通过）。覆盖范围绑定先于校验、空白匹配、部分保存、幂等、坏证据完整报告、最终提交失败不落库及修正成功，以及模拟模型的真实工具链。

未调用真实 Provider、未恢复原失败任务、未改写真实数据、未修改 PurrA 框架。未进行 Electron 验收；运行中的后端须加载本轮 Python 更新。证据匹配只验证出处与字面内容，不证明证据在语义上充分支持结论；本轮没有宣称分析准确率提升。

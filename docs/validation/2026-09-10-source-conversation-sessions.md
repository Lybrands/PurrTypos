# 来源分析使用普通会话

## 行为与根因修复

来源分析之前既在前端只展示最新 Run，又在后端查询中使用 LIMIT 1，因此即使追问读取了历史输入，界面仍会替换旧消息。

- Run 查询返回来源版本的多轮记录；回放按 Run 分开维护，再按当前会话组合展示。新轮次不重置其他轮次，刷新后复用持久事件恢复。
- 复用 AgentConversationPanel 的会话侧栏、新建、选择、重命名、关闭与历史重新打开能力；移除来源页禁用侧栏及隐藏展开按钮的配置。
- 来源版本具有持久会话及命令归属。旧记录归入默认来源对话，新建会话隔离模型公开问答上下文。重新分析仍是当前会话中的一次明确操作，不删除历史。
- 发送队列与草稿按来源版本和会话隔离。关闭只是收起会话，历史入口可重新打开。
- 后端校验会话所属来源、关闭状态与命令幂等归属；恢复任务保留原会话绑定。

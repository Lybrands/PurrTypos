# 创作资料库布局修复

- 根因：PurrButton 把 children 包在 `.purr-button__label` 中，原来的 flex 样式只作用于外层按钮，实际内容未横向排列。修复限于资料列表按钮，不修改基础按钮的全局行为。
- 名称、类型、箭头恢复单行布局，列表行高 42px，保留整行悬停、焦点与点击；长名称省略并保留 title。
- 检索和清单前置，范围/Embedding 配置移到清单后；顶部说明精简、刷新信息合并；窄面板检索输入独占一行，模式选择限制宽度；展开表单采用单列，统一内容和预览间距。
- 验证：TypeScript、Purr Components 边界检查通过；前端单元测试 476 passed；Vite 生产构建通过（保留已有大 chunk 提示）；git diff --check 通过。
- 实际浏览器检查：打开真实作品的资料库，只读检查列表、人物预览、范围展开、滚动及空结果；在 1040px 视口下，资料面板 clientWidth/scrollWidth 均为 457px，无横向溢出，列表行高测得 42px。悬停命中整行按钮。已恢复浏览器验证尺寸。
- 没有修改创作资料或保存配置，没有调用 Provider；本轮浏览器视觉验证不等同于完整 Electron 桌面验收。使用已有开发服务，没有启动新服务。

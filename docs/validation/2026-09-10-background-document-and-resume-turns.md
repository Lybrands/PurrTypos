# 故事背景文档与恢复轮次

## 结果展示与证据

故事背景在分析结果中以一个 Markdown 阅读区域展示，依据集中在文末的 PurrCollapse。保留资料编辑入口；编辑后返回文档阅读。已有背景记录直接组合展示，不调用模型重写、不删除原始证据或改变章节范围。

提取规则要求背景以连贯 Markdown 段落组织，多个原文片段可以共同支撑一条背景记录，不在背景正文逐项嵌入引文。底层仍保留 evidence 数组和来源校验：背景总结不是任意补写的许可。展示粒度与证据存储粒度独立，暂不变更已保存事实的结构。

## 恢复对话

恢复请求保留本次用户消息，控制按钮恢复使用“继续分析”。原始目标和冻结计划仍由任务保存。列表不再按 taskId 去掉旧轮次，每次 root Run 独立保留，子 Run 依据同任务中 root 创建顺序归属本轮执行；旧轮次不再附带任务最新可变单元状态或最新成果链接。

历史上已经被原始目标覆盖的“继续”消息无法反推出原文；本次不伪造旧消息。已保存的旧 root/子 Run 执行记录可以分别展示。

## 验证边界

确定性测试覆盖背景单一 Markdown 区域和文末依据、对话回放、恢复消息传递、完成计划保留、失败/恢复轮次和子 Run 分离。另运行类型检查及基础组件检查。

未使用真实 Provider 验证新背景文字质量，未进行 Electron 桌面验收，也未重跑或改写用户资料。后端变更需重新加载后生效。

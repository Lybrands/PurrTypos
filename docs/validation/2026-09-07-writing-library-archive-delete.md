# 写作技法库：归档、恢复与永久删除

## 行为

- 技法与方案均分为「库中」「已归档」，默认显示库中内容。
- 归档保留本地文件，停止执行使用；恢复后需要重新配置授权。
- 永久删除仅在归档内容中提供。确认界面显示草稿及版本数量，并说明历史引用无法继续读取。
- 删除技法前检查全部现存方案（包括归档方案）的非取消草稿、封存稿和已发布版本。存在引用时阻止删除并列出方案。
- 删除方案不会删除成员技法。
- 删除确认令牌覆盖对象和草稿状态，执行时重新检查引用和状态。
- 本地保留最小删除回执，正文、草稿和版本目录实际清理。重试不会恢复已删除内容，旧创建请求也不能复活对象。

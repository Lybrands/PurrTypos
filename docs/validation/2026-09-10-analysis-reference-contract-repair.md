# 原文引用协议与纠错

引用类型明确提供 quote/chapter。旧混合参数携带实际 excerpt 时按精确引文校验，不能以 chapter 绕过引文验证；没有引文的关键资料仍拒绝。类型错误提供直接可执行的 quote/sourceSpanId 修正格式，批量报错不再一律要求重新抄引文。

新增 findAnalysisSourceEvidence，仅在当前提取片段内用原文关键词选取至多八段、每段至多 160 字的候选。返回绑定版本、章节、位置和内容摘要的 sourceSpanId。分批保存及最终提交都在宿主解引用，并再次校验原文；不允许跨范围、改动编号或额外混入引文字段。重复原文可按选定范围校验。无匹配时返回空列表，要求更换关键词，不做模糊认领。

普通情绪与短暂反应使用 character_summary，总体关系印象使用 relationship_summary，允许章节来源。生死、持续伤病、知情和明确关系变化仍使用受保护类型。同步提取提示中的完整类型列表、单片段概览规则、继承映射及展示。

回归以本次 Run 的混合字段、删引文、改写代词等参数形态构造临时资料；没有复制真实小说进入测试仓库。验证混合字段一次保存、改写引文仍拒绝、选择编号后提交成功、编号篡改/越界拒绝，以及提交、发布和继承的既有约束。

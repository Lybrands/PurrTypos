## 真实网络与浏览器

真实无 Key 降级使用独立临时数据库，经生产工具执行器执行英文公开查询 `Python programming language documentation`：`searchProvider=free,fallbackReason=missing_api_key`，Bing RSS 返回三条来源，查询额度使用一次；读取首条得到 **1,545 字符**正文，读取额度使用一次。没有 DeepSeek 或生成模型请求。此项证明免费降级与读取链路可用，不证明检索相关性或答案准确率。摘要元数据保存在会话临时文件 `/private/tmp/purrtypos-deepseek-free-smoke.json`。

真实 Web 界面使用独立空数据库、临时后端 18325 和前端 5175，未更改用户日常数据。内置浏览器跨端口测试首先出现设置加载失败，后端只读接口检查正常；改用临时同源代理后完成以下操作，生产请求配置未修改：

1. 默认联网关闭，下级选项隐藏；打开后默认 DeepSeek 优先且显示无 Key 免费降级。
2. 选择免费服务，Key 输入框隐藏；切回 DeepSeek 后仍显示无 Key 降级。
3. 输入明确无效的 UI 测试占位值，仅保存到临时库，没有发起 DeepSeek 查询；按钮启用，保存后输入框清空并提供更新、删除操作。
4. 页面重载后仍显示已配置状态，输入框没有回填原值；删除测试占位值后恢复无 Key 免费降级。

## 未验证与边界

没有提供真实 DeepSeek Search Key，因此尚未验证实际鉴权、账户余额/计费、真实搜索结果及可用性；HTTP 模拟通过不能替代供应商验收。没有做 DeepSeek 与免费路径的相关性、日期正确性或引用支持率对比，也没有消除模型错误引用的风险。来源评分是供应商元数据，不是准确率。未进行 Electron/Windows 原生窗口、安装包和分发环境验收。

Key 持久化在本机 settings 数据库，并非加密保险库；API 不回显原值，不复用写作模型 Key。取消已发出的收费请求不能保证服务商没有计费，失败 API 不自动切换免费服务或重试；无 Key 才自动降级。配置变更在新搜索批次生效，重放保留原结果。网页正文仍由本机读取，搜索接入不会使本机难以抓取的网站自动可读。

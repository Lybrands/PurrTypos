# 来源分析与追问分离

## 行为

- 输入框只提交普通追问，不再根据分析 Artifact 是否存在自动启动完整分析。
- 首次分析使用“快速分析”；有分析记录或结果后显示“重新分析”。完整分析仍走既有版本化任务与结果流程，不删除旧记录；新结果完成后切换展示。
- 没有完整分析结果时允许就原文提问。有结果时附带该分析的有限摘要；继续沿用持久化公开问答上下文。
- 追问仅开放当前来源版本的目录、原文分段读取，以及存在分析结果时的固定版本技法读取。原文每次最多 8000 字符，支持位置续读；禁止读取绑定范围外章节。追问不开放分析提交或资料写入工具。

## 验证

- 确定性后端：novel_analysis_conversation 与 novel_analysis 共 101 项通过；agent_conversation_input 12 项通过。
- 前端页面行为测试通过，包含无 Artifact 提问仅调用追问接口，以及恢复、排队、切换来源后的草稿隔离。
- TypeScript、基础组件边界检查、改动文件 diff 检查通过。
- 未调用真实 Provider，未进行本机 Electron 端到端验收；未修改真实创作资料或历史数据库。后端进程需要加载本轮 Python 更新才能使用可选 Artifact 和原文工具。

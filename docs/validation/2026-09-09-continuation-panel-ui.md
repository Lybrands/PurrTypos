# 续写工作台面板 UI

## 已实现

- 人物和世界设定继续使用普通作品列表，移除行内额外的继承展开块；只读基线在编辑详情中使用 PurrCollapse 展示。
- 故事背景、原作时间线、记忆来源详情使用 PurrCollapse。
- 继承正史补充面板留白、卡片排版、中文类型名称；字符串按 Markdown 展示，结构化值按字段或列表展示，不再直接序列化 JSON。
- 技法授权列表使用名称，隐藏内部 ID；已授权的准确版本在 PurrSelect 中禁用并提供说明，提交处理也阻止重复授权。
- 保持继承基线只读，不修改实际作品数据。

## 验证

- TypeScript 检查通过。
- Purr Components 边界检查通过。
- 476 项前端单元测试通过。
- Vite 前端构建通过，保留现有大 chunk 提示。
- Codex 内置浏览器访问本地运行中的续写作品 KqFhvkCS：核对人物列表、正史卡片排版和滚动、时间线展开；下拉中已授权项具有 disabled 状态，显示技法名称。
- 未执行授权/撤销/编辑保存，不改动真实作品内容；未进行 Electron 独立验收或真实 Provider 调用。

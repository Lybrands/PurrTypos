# 小说分析对话接续

## 行为

同一会话发送“继续”“继续分析”“继续执行”“接着分析”“恢复分析”（或 continue/resume）时，若最近分析任务失败或暂停，调用既有 durable task 恢复入口。沿用冻结计划和原始分析目标，保留已完成单元；失败单元走重试，暂停任务走恢复。取消或已完成任务不自动恢复，不自动新建完整分析。

普通问题仍走对话入口，可在暂停时追问。上下文增加当前会话的任务状态、原始目标和完成数量，并提供分页成果目录与成果读取工具。成果限定当前来源版本、当前会话最近任务，不一次性装载全部结果。失败状态下与错误字段相同的 final_response 不作为正常回答送入历史。

前端不再把暂停任务当作消息发送和队列消费的阻塞条件；正在执行的分析仍阻塞队列消费。重新分析入口保留原有规则。

## 验证

- 后端相关回归：119 项通过（对话输入、会话隔离、分析恢复、分析工具、成果读取）。新增用例覆盖失败/暂停继续路由、普通追问不恢复、跨会话成果拒绝、错误码不进入对话历史。
- 前端对话回放和输入队列：26 项通过。
- TypeScript 类型检查通过；git diff --check 通过。
- 本轮未调用真实 Provider，未重跑用户任务，未做 Electron 桌面验收。后端需加载修改后的代码才生效。

## 边界

接续依赖已持久化的单元和成果，不恢复未落盘的模型输出，也不保证逐 token 接续失败输出。旧任务若缺少冻结计划或 schema 不兼容，恢复入口仍明确报错，不静默从头分析。普通追问按需读取成果，不承诺模型每次会主动读取全部成果。

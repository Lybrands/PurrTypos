# 来源分析创作资料改造验证

对应计划：[`来源分析产物与证据引用改造`](../design/2026-09-08-source-analysis-materials-plan.md)。

## 实现

- 新分析不再增加故事概览聚合调用，旧概览仍能查看，创建新续写时不把概览写入正史。
- 结果显示人物资料、背景与设定、情节与续写起点、写作技法；未知类型显示为待分类资料。文本资料使用共享 Markdown 编辑器修订，技法沿用已有文件树及编辑组件。
- 归一模型读取 evidenceId，按需批量补读引文；ID 绑定当前来源版本和冻结单元输入。宿主保留未返回事实及不同章节范围，只采纳有对应事实与证据的实体名称归一。
- 情节使用 plot 继承分类，不再创建普通设定实体；写作上下文保留冻结情节，人物和背景设定读取共享 Markdown。继承正文保留章节出处，完整依据存在冻结记录中。
- 提取支持 appendAnalysisFacts 分批保存；逐字引文在落批次前校验，最终由程序汇总，重放同一工具调用幂等。

### 内容审阅与测试请求范围

人工检查生成技法发现：把追逐场景概括为“每句控制在三四字至六七字”，并把局部情感曲线写成固定路径；部分示例也过于贴近来源。它违反已有提示词中的可调整建议边界，不能将结构校验通过等同于内容质量合格。验证未改写验收样本以伪装模型原生输出。

原验收脚本默认遍历 E02 全部独立使用项，额外发送了不在约定测试范围内的 U02a“退役选手整理号码布”合成请求，且因段落要求重试一次。未发送小说原稿。脚本现默认只分析，独立使用必须显式列出 `--independent-use-id`，后续测试限定 `--independent-use-id U02b`。`--freeze-only` 检查确认白名单只含 U02b，未再调用模型。U02a 不计入约定范围的验收结论。

验证未以可比完整样本证明耗时或 token 下降。冻结产物仍保存兼容的引文，未做历史证据表迁移；引用优化首先作用于模型输入。结构化对象资料仍只读，文本资料可修订。

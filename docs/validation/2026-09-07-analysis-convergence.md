## 实现

- 宿主在冻结输入中提供 observationCount，包括零值；无上游观察的来源分析单元不开放目录与观察读取工具。提交和分批保存能力保持可用；有上游观察时仍支持分页浏览和按 ID 读取。技法生成阶段维持既有工具集合。
- 提取的完成条件是有逐字证据、具体写法和效果；条件及歧义只限证据支持的范围，不穷尽假设，不把数量上限当目标。没有依据允许空数组。

- 明确由现有代码负责来源定位、证据匹配、精确去重、未合并观察保留、覆盖率及事实键值冲突统计。语义等价、效果与适用条件仍由模型判断。该变更复用既有实现，没有把语义判断替换成字符串去重。

# 输出截断：拆分短材料分析职责

## 修改范围

仅处理第一类问题（单次调用未完成而耗尽生成预算），不处理观察准确性或技法质量。

取消单章节、单片段且不超过 4,000 字时的合并优化。单片段新任务依次进行提取、概览和技法生成，不新增跨片段语义归一；短材料模型单元由 2 个变为 3 个，总单元由 5 个变为 6 个。多片段仍保留原来的归一流程。沿用已有执行器、分阶段产物、恢复和校验路径。预算、推理配置及重试次数未提高。

现有冻结任务仍按已持久化的 recipe 恢复；执行器保留旧 includeStoryOverview 契约，不将历史任务强行换成新步骤。该变更不改变结构化结果或公开回复契约。

成本风险：单次职责减少，但请求次数及跨阶段上下文可能增加；不能仅凭不截断认定性能改善。

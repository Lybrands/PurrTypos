# 小说分析消息编辑重发

状态：代码完成；确定性验证通过，未做真实 Provider 或 Electron 桌面验收。

## 行为

- 编辑已发送的消息后，从该消息所在位置重新执行，保留此前对话。
- 原消息及后续轮次退出当前对话分支，不再进入历史上下文、自动任务续接或实时输出；原 Run、子 Run 与资料产物仍保留。
- 编辑普通追问仍执行追问，编辑完整分析则重新启动分析。执行使用新的 Run ID，保留独立的诊断记录。
- 请求携带目标 Run ID，并冻结来源、对话与模型配置。后端校验归属、终态与幂等关系；未接受请求时，事务回滚分支变更。
- 编辑请求只能使用编辑点之前的结果引用；普通追问从当前对话的有效 Run 读取结果引用，不使用结果预览弹窗的临时状态。
- 公共对话组件仍负责定位消息并传递编辑事件；业务接入负责执行上述替换语义，接口注释已明确此约定。

## 验证

- 40 项后端测试：编辑分支、上下文前缀、同来源不同对话隔离、重开数据库恢复、重复请求、过期目标、拒绝回滚、HTTP 参数、分析/追问分流，以及既有分析执行与续接回归。
- 27 项前端测试：实际编辑请求带原 Run ID、替换后消息展示、草稿保留、会话切换与公共组件编辑定位，以及历史/流式投影回归。
- TypeScript 检查通过。
- 全部使用临时数据库、模拟接口或确定性 Provider 替身；没有发送真实模型请求、修改个人创作资料或重启用户正在使用的后端。

后端重新启动后加载新增的分支存档表和接口逻辑；仅刷新前端不足以启用本次修复。

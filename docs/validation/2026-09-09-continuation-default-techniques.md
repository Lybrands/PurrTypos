# 续写默认继承来源技法

## 行为

新建续写默认选择“使用来源作品的写作技法”，可切换“无写作技法”。移除“我选择无默认技法创建”确认框及创建按钮阻塞条件。来源没有可继承技法时，显示简短提示并允许创建；显式选择无技法时，不授予来源技法或设置默认选择。

候选可继承性只在续写预览中启用，不改变普通来源页对候选/已发布版本的区分。候选必须可读取、文件验证通过、未归档且分析覆盖不超过分叉点；已有发布版本优先。页面显示技法名称，不显示内部 ID 和版本摘要。

创建时将所选候选的固定版本复制为库草稿，封存、发布并设置作品默认。保持来源候选不变，复制所有版本文件并保留来源分析、来源版本和原始技法引用。复制使用稳定操作 ID；SQL/资料文件失败时，可重试复用已保存的技法副本，避免重复副本。技法文件存储不随外层 SQL 回滚，失败后已生成的库副本可能保留，重试会复用。

`useSourceTechniques` 默认 true。旧 `allowWithoutTechniques` 参数暂保留兼容已有调用，但不再作为无技法创建的门槛。来源版本、分叉点、证据、预览摘要和创建幂等性校验保持。

## 继承内容自动展示

来源版本、分析与分叉点选齐后自动读取并展示继承内容，移除手动预览及重新预览按钮。选择变化时清除旧清单，忽略过期请求返回；正在读取时不能提交旧摘要。技法使用偏好在自动更新时保留，重新打开创建页时默认使用来源技法。底部仅保留取消和创建按钮；读取失败时才提供重试入口，服务端报告摘要变化时自动重新读取。类型检查、组件边界、476 项前端单元测试、Vite 构建通过；本次未执行真实作品创建。

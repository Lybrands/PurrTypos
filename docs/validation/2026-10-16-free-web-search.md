## 批量查询与候选扩容（2026-10-19，feat/1.0.1）

当前 `searchWeb` 仅接受 `queries=[{query,language?}]`，每次 1–3 项，最多两路并发；同语言、规范化空白后相同的查询在批内只执行一次，逐项报告保持输入顺序。`maxResults` 默认 10、最多 20，同时限制每查询候选数与合并总数；按上游排名交错合并、用规范化 URL 键去重，每条摘要最多 300 字符。上游不足不自动追加查询凑数。来源原 URL 保留用于读取和引用。

每 Run 最多 6 个实际查询，失败也计数，`search_batch` 父回执不扣查询额度。新页面访问默认 8 次，复杂、多维或跨语言调研可显式选择 `researchMode=extended` 提升至 12，后续 standard 不降低上限。额度持久化且随 Run 删除清理；缓存分页与幂等重放不增加外部访问。搜索和读取返回 `queryBudget/readBudget` 快照，重放返回原快照。模型指导要求先筛选相关、权威且独立来源，已知多个来源时批量读取，证据足够即结束，不用满额度作为目标。读取每批 1–5 项、两路并发、8,000 字符总量及五项每项 1,600 字符规则保持。

# 对话输入框业务操作菜单

状态：已实施，等待 Electron 桌面验收。

共享 `AgentConversationExtensions` 提供 `composerActionMenu`，业务可配置触发字符、标题、按钮文案和菜单内容。操作层显示在输入框上方，是局部浮层，不使用 Modal，也不遮挡或锁定页面；底部保留紧凑的加号入口。

小说、来源分析、剧本三处均用正斜杠 `/` 触发。输入框起始位置或空白后输入 `/` 时打开操作层；中文输入法组合输入期间不触发，路径等词内字符不触发。方向键可进入并遍历操作，Enter 使用当前聚焦控件。

关闭语义区分取消、普通输入与执行操作：Esc 或点击浮层外部只关闭菜单，保留输入框中的 `/`；删除 `/` 会直接关闭；输入 `/ ` 会关闭菜单并完整保留 `/ `，表示用户想输入普通斜杠。只有选择一项操作时才消费本次 `/` 触发片段。通过底部加号打开菜单时，关闭不会修改草稿。

小说对话固定使用 Agent 执行，不再提供“问答/智能体”模式切换。小说菜单包含关联章节/大纲、设定与记忆、提示词模板，以及一体化的写作技法区：机器人图标按钮负责开启或关闭自动选择，技法和方案直接在下方以列表勾选。这里仅负责本轮选择，不提供上传或技法库管理能力。模型选择只保留在输入框底部，不在菜单内重复。

来源分析菜单保留查看原文、查看分析结果和快速分析。剧本菜单保留查看版本与文档、开始当前阶段任务、模型与应用设置。两处模型选择同样只保留在输入框底部。各操作沿用原回调及禁用条件，不因打开菜单自动提交任务。

确定性验证覆盖触发字符、光标中段、输入法组合、路径字符、删除触发字符和 `/ ` 普通输入语义。真实 Provider 调用和 Agent 效果不属于这项界面改造的验证范围。

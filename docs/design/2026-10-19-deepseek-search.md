# DeepSeek 搜索与免费搜索降级

独立 Search API 接入现有 `searchWeb`，写作模型和 `readWebPages` 保持原合同。接口依据 [DeepSeek 官方指南](https://api-docs.deepseek.com/zh-cn/guides/search/) 与 [Search Reference](https://api-docs.deepseek.com/zh-cn/api/search/)（2026-10-19 核实）。网页正文继续由本机读取，本次未接入收费 Fetch API。

## 设置与凭据

设置页按照「允许联网 → 搜索服务 → API Key」联动。总开关默认关闭；打开后可选 `DeepSeek 优先` 或 `免费搜索`。默认偏好 DeepSeek，只有用户保存独立搜索 Key 后才会请求该服务；没有 Key 自动使用免费搜索并在回执中说明。选免费搜索时，即使已有 Key 也只用免费服务；关闭或切换服务不会删除 Key，删除按钮才会清除。未保存的 Key 草稿不会改变实际路由。保存失败保留已确认设置，提交过程中锁定关联控件。

- `web_search_enabled`：现有联网权限开关，继续保留新 Run 授权与逐次全局校验。
- `web_search_provider`：`deepseek`（默认）或 `free`。
- `web_search_deepseek_api_key`：仅写入，空字符串删除；不复用写作模型的 Key。
- `web_search_deepseek_api_key_configured`：只读状态；GET 设置不返回原 Key，回传此状态不会修改凭据。

Key 保存在本机 settings 数据库，与其他本地配置一同留存，并非加密保险库。Key 不进入工具参数、来源记录、Run 回执、检查点、提示词或最终答复，仅在请求固定官方 HTTPS 地址时放入 Authorization 头。浏览器输入框只接受替换值，不填充已保存 Key。修改设置在事务中原子落库，非法组合不会部分应用。

## 搜索合同

每个批次在授权与幂等检查后读取一次路由配置，批内共享该快照，避免执行中改设置产生混合供应商。回放先使用原回执，不重新读取 Key 或访问搜索服务。新批次使用最新配置。

DeepSeek 请求固定为 `POST https://api.deepseek.com/v1/tools/search`，提交 query、count 和 `need_content=false`。不发送用户原始会话、正文或用户 IP。保留单次 1–3 查询、两路并发、每 Run 6 个实际查询尝试、候选默认 10 / 上限 20；逐项失败不影响其他查询。DeepSeek 的 query 限制为 128 Unicode 字符，超限明确返回错误，不截断检索词；免费服务仍允许原有 300 字符。工具说明建议短查询，并说明 DeepSeek 可在 query 中使用站点、语言和日期操作符；language 只对免费服务表达地区偏好。

DeepSeek 返回来源的发表时间、排序分数与权威性等级经过类型和范围检查后留存、回传；未知日期保持 null，合法日期归一至 UTC。分数只表达供应商的排序依据，不是事实准确率，不跨查询重新解释为统一置信度。搜索正文不返回，仍由短摘要筛选后通过现有批量读取获得原文；来源 URL 校验、DNS/重定向 SSRF 防护、缓存、分页、8/12 新页面上限与正文总预算继续生效。旧数据库通过增量列迁移保留已有来源和缓存。

`searchProvider` 表示本批实际服务；无 Key 时 `fallbackReason=missing_api_key`。只有无 Key 自动降级，已配置 Key 的 401、402、429、超时及服务错误会明确返回，用户可更新 Key 或主动切换免费搜索，不会悄悄扩大请求接收方。正常空结果与 API 失败分开报告。按既有规则预留的失败查询尝试也消耗本 Run 额度。

## 网络与费用边界

官方 API 使用 Bearer 鉴权，按成功且有结果的请求计费；每条候选数不决定单次请求价格，以服务商当期规则为准。界面提示独立搜索费用以及模型用量、响应时间影响。客户端不跟随 API 重定向、不使用环境代理，响应上限 2 MB；错误信息不透传服务商响应正文或异常中的凭据。没有自动重试付费 API，同一调用幂等重放不会重复发送；取消已发送请求不能保证供应商没有计费。

接入供应商不能替代事实核验。发布日期、摘要和评分均可能缺失或有误，网页正文仍可能受提取或分页影响；模型须核对原文、适用时间与独立来源，引用实际返回的 URL。尚无自动引用语义校验，也没有通过对比评测证明 DeepSeek 比免费路径更准确。

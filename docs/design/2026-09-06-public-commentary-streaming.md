# 公开执行说明的增量输出

小说分析、小说写作和剧本共用 `PublicCommentaryOutputProcessor`。它扩展已安装 PurrA 0.5.0 的输出处理器，继续使用同一公共事件日志、publisher、SSE 和前端 reducer，不修改依赖版本或重建私有调用的最终答复。

模型在工具轮次正文开头用 `【公开说明】` 与 `【说明结束】` 明确界定可直接展示的说明。解析器跨 Provider chunk 识别边界，保留正文中的换行、列表和长度；标记外的文本、思考字段、工具参数不进入该公开投影。没有标记的旧调用保持原框架行为，不把尚未确定语义的候选全文实时公开。

每个公开正文增量先确保其 Provider 原始字节已持久化，再写入原 output stream 对应的 canonical `provider.content_delta/commentary` 并发布。没有模拟打字或额外模型调用。提交、失败和 Run 强制终止均在原日志收口，历史重放复用事件身份。已经增量发布的说明不能再走整轮内容转 commentary 的回退路径。

前端公开说明正文不再使用状态标题的 280 字、单行、非列表过滤器。状态标题仍保持简短；公开说明按同一 stream 稳定更新。私有结构化结果没有因此成为公开正文。

小说分析内部单元声明 `responseAudience=internal`、`progressAudience=public`。根任务也明确要求公开进展，不因未开放业务工具而缺失执行说明策略；规划协议仍由框架独立解析，不经过正文标记解析器。

验证包括：真实 SQLite 与 canonical SSE 序列化在模型未完成时读取第一段；小说分析单元和写作 HTTP 入口的 Provider 模拟回归在后续工具参数尚未生成时检查公开日志；分片标记、多段长文本、结束不重发、失败收口及前端增量重放。上述证据是确定性验证，不代表实际 Provider 一定遵循标记协议，也不代表已完成真实小说蒸馏。

最终 `npm run check:agent-refactor` 通过：前端 436 项、后端 2,077 项，包含类型与架构检查。本轮没有新增真实 Provider 调用。检查时默认后端端口 18321 未监听，因此没有重启用户进程；下次启动后端会加载新代码。

## P1：收到公开 chunk 后立即更新

公开 `final_public` / `execution_public` 调用在每次接收 Provider chunk 后立即提交日志批次并通知订阅者，不再等待批次计时器。一个 Provider chunk 内的协议字段仍保持同批，不拆成模拟字符。

小说写作通过 `flushSync` 提交每次 chunk 的 React 状态更新；小说分析逐条分发分页内的事件并提交显示，`hasMore` 不再阻止显示，已发布分析的查询也不阻塞 SSE 消费。剧本同样逐条提交，包括历史追赶与终态重放；已经获得当前会话消息后，追赶状态不再遮住正文。切换项目和会话的身份隔离仍保留。浏览器实际绘制受显示帧率限制，DOM 提交不再由应用定时器合并。

新增回归覆盖同一页内两个 chunk 的逐次文本、后续分页尚未返回时的显示、重放去重、挂载 React DOM 在处理下一 chunk 前已更新，以及公开 final/commentary 在模型尚未结束时可从 SQLite/SSE 读到每个 Provider chunk。

P1 验证结果：前端 438 项、后端 2,079 项通过，类型检查、架构检查、Web 构建和 `git diff --check` 通过。旧后端进程仍在运行，尚未重启；本次没有追加真实 Provider 调用或实际浏览器端到端验收。运行中的应用需重启后端后再验证新行为。

## 内部执行阶段不得静默执行工具

仅有输出解析器不能保证模型提供公开说明。共享 `RequiredPublicProgress` 在内部产物、公开进展的工具阶段检查当前 Run 的持久化 commentary。非空且未中止的公开说明才允许业务 handler 执行，工具的 scope、权限和副作用控制继续保留。缺失时返回 `tool_input_invalid`，内容说明 `public_progress_required`，效果为 `NOT_STARTED`，由 Core 原有有限修正机制处理；终态校验同时阻止尚未通过门槛的阶段直接完成。

模型正常遵循公开边界协议时，真实 chunk 继续即时发布，不产生额外模型调用。遗漏时只使用既有修正额度，不改用户模型参数或任务预算。历史消息、其他阶段、被中止的流和私有文本不能替代当前阶段说明。剧本场景指令将“最终只输出场景正文”与工具执行前的说明分开。

回归覆盖小说分析先静默提交、修正后增量输出再提交、持续静默有界失败，以及剧本正式任务首次静默工具调用后修正并正常交付。共享输出测试检查流中止后失去放行资格。该约束不承诺模型在固定秒数内结束思考；真实 Provider 的时间与效果仍须使用重启后的新 Run 验证。

本次修复验证：`npm run check:agent-refactor` 通过，前端 454 项、后端 2,147 项；Web 构建通过。既有后端未重启，本次未发起真实 Provider 调用，历史 Run 不作为修复后的验收证据。

## 真实模型验证状态

本机配置中存在 selectable 与 always-enabled 两类模型 Profile，但本轮没有形成真实供应商 E2E 通过证据。

- 沙箱内最小请求因 DNS/网络隔离失败，未到达供应商；
- 请求外部网络权限时，安全审查因可能读取本机密钥并产生费用而拒绝；
- 没有绕过权限限制，也没有把模拟网关测试声明成真实供应商验证；
- 验证使用的临时数据库副本和脚本已删除；
- 本轮没有启动应用、Vite 或后端服务。现有 5173 监听进程不属于本轮，未做修改。

因此，当前可确认的是确定性协议、持久化和重放门禁通过；真实供应商兼容性仍需用户明确授权后，针对指定 Profile 执行最小付费验证。授权前不能把该项标记为完成。

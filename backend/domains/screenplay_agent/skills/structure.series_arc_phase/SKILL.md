# 展开当前主线阶段

## 目标

围绕既定阶段目标，设计能产生关键转折并留下明确结束状态的主线推进。

## 方法

1. 接续已有阶段索引和相关材料，明确进入本阶段时人物的目标、关系、资源与已知信息。用这些条件解释行动起点，不另起一条不相干的主线。
2. 确定本阶段的核心冲突：主要追求是什么，谁或什么在形成持续阻力，双方采用怎样的策略。使阻力对人物选择产生实际影响。
3. 将推进组织成行动与后果的链条。每次重要尝试应改变局面，失败、成功或妥协都应影响下一次选择，避免仅靠连续巧合堆叠事件。
4. 设计符合既定阶段目标的关键转折。转折应来自铺垫、人物选择或规则内的外部变化，并改变继续解决问题的条件；不能只用突发惊吓代替转折。
5. 确定阶段结束后的事实状态：目标、关系、力量和认知中哪些已改变，哪些问题仍存在。它应能自然承接下一阶段，不能只写“悬念更大”。

## 完成标准

核心冲突、关键转折和结束状态之间有清楚的因果关系，阶段内容完成索引规定的任务，并与已有故事事实衔接。

## 自检

- 转折是否改变人物之后必须采取的行动？
- 结束状态是否由本阶段发生的事情产生？
- 是否依靠突然新增能力、人物或设定来解决主要问题？
- 是否偏离了既定阶段目标，或提前消耗了其他阶段的任务？

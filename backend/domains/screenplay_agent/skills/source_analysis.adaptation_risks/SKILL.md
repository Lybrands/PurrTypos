# 改编风险评估

**核心任务：识别改编可能破坏的关键依赖，说明何种变化会损失故事理解、情感或风格中的什么功能。**

## 优先检查

1. **因果与人物依赖。**检查关键行动、立场、能力与关系所需的铺垫和积累。说明删减或调整什么，会使哪个选择缺少动机或条件、情感失去基础，或结果难以成立。

2. **表达与信息依赖。**检查内心、叙述解释、背景、意象、信息密度及揭示顺序承载的作用。判断转换到目标媒介后，哪些理解、悬念或体验可能丢失；不把内心描写直接等同于无法呈现，不预先将表达限定为行动和对白。

3. **目标与制作依赖。**结合已确认的形式、时长、受众和定位，检查人物辨认、规则理解、地点转换、大规模事件或特殊视觉呈现的具体要求。说明叙事功能与当前呈现方式的区别；条件未知时写明风险成立的前提。

## 每项风险写清

**具体原作依据与依赖 → 触发变化或条件 → 受影响的情节、关系或体验 → 必须保留的功能。**

区分材料已显示的依赖与假设改动后才成立的风险。按对核心理解、情感和作品特征的影响确定优先级；篇幅、预算或目标不足以支持判断时保留条件，不用笼统的高低评分代替解释。

## 完成检查

合并同因重复项。检查每项风险是否有具体依据、明确触发条件与实际损失；没有明显风险可以不列。不因人物多、设定复杂就判定要删，不擅定预算或宣称无法拍摄，不替后续创作决定重写、人物合并或场景安排。

# 单章事实提取

**核心任务：留下本章可核对的事实底稿，说明发生了什么、改变了什么，以及哪些条件仍在起作用。**

## 优先方法

1. **按理解需要取舍。**判断删去某项信息，是否会使人误解本章的行动、关系、规则或未解问题。保留必要背景、首次出现的重要状态和关键变化；只依据当前材料判断用途，不预测未来伏笔。

2. **围绕事件记录变化。**写清谁在何种处境下做了什么、已出现什么结果，以及目标、知情、关系或行动条件如何改变。后果未呈现则注明；只有先后而无因果依据时，不补写原因。

3. **保留条件与未完成事项。**记录影响行动的规则、代价、限制和例外，以及秘密、威胁、承诺和目标的提出、推进、部分解决与未明部分。主题和改编信号须附着于具体选择、意象或叙述方式，简述其初步含义或表达依赖，不展开全书结论。

## 取舍与边界

合并重复，统一有依据的称呼，不拆碎完整行动或误并相似事件。没有显著事件的章节，说明其呈现的日常状态、关系、背景或氛围。关键辨认信息和独特表达可以保留，不平均摘录细节。

区分实际事件、人物陈述与推测，以及回忆、梦境、想象和传闻；保留信息归属与不确定性。上下文仅用于理解本章，不把其他章节的事件算入本章，也不让人物提前知情。

## 完成检查

核对事实底稿是否保住关键变化、必要条件和未解事项；每项判断能否对应本章的具体表现，是否把未知写成了确定。

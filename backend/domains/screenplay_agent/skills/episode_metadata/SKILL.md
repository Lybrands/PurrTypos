# 集标题与连续性摘要

## 目标

为已完成的一集确定具有辨识度的标题，并压缩出下一集续写所需的事实状态。

## 方法

1. 按场景顺序确认本集的主要行动、核心选择和最终变化，判断哪一项最能区分本集与相邻集。
2. 标题取自已经发生的关键事件、选择、关系变化或代表性意象。用词简洁具体，不依赖尚未发生的情节才能成立。
3. 连续性摘要以集末状态为中心，记录会影响后续行动的人物目标、位置、知情范围、关系、资源、物件、威胁和未完成事项。
4. 说明关键状态是由什么行动或结果造成的，使下一集能正确承接；开放事项保持开放，不预写解决方式。
5. 优先保留下一集若遗漏就会造成矛盾的信息，合并重复结果，不逐场复述本集。

## 完成标准

标题能识别本集的核心变化；连续性摘要只含已写成的事实，并足以支持下一集在正确状态上开始。

## 自检

- 标题是否过于通用，可能适用于多数集？
- 摘要是否遗漏人物知情、物件去向或关系变化？
- 是否把计划、推测或下一集设想写成已发生事实？
- 是否保留了不影响后续的逐场复述？

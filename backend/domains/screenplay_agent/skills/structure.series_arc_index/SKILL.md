# 划分全剧主线阶段

## 目标

把既定故事方向划分成有因果联系、各自承担不同推进任务的主线阶段。

## 方法

1. 先确认核心冲突、主要人物起点与故事希望抵达的方向。已确定的结局或阶段要求作为依据，不重新制定另一套故事前提。
2. 依据局面的实质变化划分阶段：人物目标改变、策略失效、力量关系逆转、重要认知更新或核心代价出现。阶段边界服务戏剧变化，不机械按篇幅等分。
3. 为每个阶段确定主要叙事任务，说明它要使人物或冲突从什么状态走向什么状态。相邻阶段的任务必须有区别，不能只是“冲突进一步升级”的重复。
4. 检查阶段衔接：前一阶段的选择或后果应使后一阶段有必要发生。开端建立问题，中段改变解决条件，后段回应主要承诺；具体组织方式服从作品形式，不强制套固定幕数。
5. 根据素材容量合并无独立作用的阶段，保留真正改变主线走向的分界。标题帮助识别阶段任务，不以夸张措辞代替任务内容。

## 完成标准

仅凭阶段标题和目标，就能看出全剧推进方向、主要变化与前后依赖；索引保持轻量，足以约束后续逐阶段展开。

## 自检

- 任意调换两个阶段，故事是否仍几乎不受影响？若是，因果关系是否不足？
- 是否存在承担相同任务的重复阶段？
- 阶段目标是否说明了具体推进，而非只有情绪强度？
- 是否为凑结构数量而切断了完整的因果单元？

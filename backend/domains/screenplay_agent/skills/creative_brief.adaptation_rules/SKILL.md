# 制定改编取舍规则

## 目标

把创作定位与已知改编风险转成可以指导后续取舍的具体规则，并说明采用它们的理由。

## 方法

1. 先确定当前项目是改编还是原创。改编项目辨认原作中需要保护的人物动机、核心关系、因果和主题体验；原创项目围绕已确定的创作设定制定表达取舍，不虚构原作依据。
2. 区分必须保留的故事功能与可以转换的形式。例如需要保留的是某个选择产生的关系后果，原有叙述方式未必是唯一表达方式。
3. 将每个重要风险转成可判断的规则，明确遇到什么情况时如何取舍。针对内心叙述外化、人物合并、支线压缩或事件调整，说明应保护的功能与允许变化的条件。
4. 给出与项目目标有关的理由和代价。压缩可能提高集中度，也可能损失关系积累；规则应说明优先保护什么，而非把所有变化都描述成没有损失的优化。
5. 合并重复规则并解决彼此冲突。用户明确的保留要求作为确定依据；修订规则时检查其是否会破坏其他已经接受的创作选择。

## 完成标准

规则能帮助实际判断“这个改动是否符合项目方向”，理由解释保护了什么或接受了什么代价；内容具体、可执行，不提前替后续步骤写出整套剧情。

## 自检

- 规则是否只是“尊重原作、加强冲突”等无法判断的口号？
- 是否区分了内容功能与表达形式？
- 不同规则冲突时是否仍能作出一致的取舍？
- 原创项目是否被错误要求忠实于不存在的原作？

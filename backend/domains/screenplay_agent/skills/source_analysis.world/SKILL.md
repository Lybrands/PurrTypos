# 世界观分析

**核心任务：说明故事中的规则、生活条件与空间社会关系，怎样限制或支持人物行动，并形成这个世界的特征。**

## 优先方法

1. **从行动提取规则。**结合人物能做什么、受什么限制及承担什么代价，整理适用对象、触发条件、资源、后果与例外。现实题材同样关注材料中的制度、经济条件和社会惯例；没有依据的部分保持未知。

2. **解释空间与社会关系。**说明重要地点的用途、通行条件和环境限制，以及组织、群体与身份之间的控制、依赖、合作和冲突。将这些条件落实到人物的机会与阻力，不只罗列名称。

3. **区分规则与说法。**对照实际事件、人物理解、组织宣称和传闻。出现差异时核对时间、地点、身份与适用条件；依据不足则保留差异，区分明确矛盾和解释缺失。

## 取舍标准

优先保留解释关键因果、身份与行为所必需的设定；对持续塑造生活方式、氛围或作品辨识度的风俗、环境与物件，简述其具体作用。无关背景与名称列表可以简化，不补写百科式设定。

## 完成检查

关键规则能否说明适用条件、实际影响与已知边界？是否把一次成功当成无限能力，把一次违规当成规则失效，或用类型惯例和现实常识替原作补设定？无法确认的距离、规模和制度解释保持未知。

# 制定世界规则与视觉识别

## 目标

选择能够支撑当前故事的世界约束，并形成与人物处境、作品调性相符的视觉表达方向。

## 方法

1. 从核心冲突反推必须清楚的规则：人物拥有什么资源、受什么制度或能力限制、越界会承担什么后果。优先保留影响选择的规则，不追求百科式设定量。
2. 对改编项目沿用已确认的世界事实，按已明确的改编取向处理表达；对原创项目补足推进故事必需的设定，同时保持内部一致。
3. 检查每条便利条件是否有适用范围和代价。规则应同时约束不同人物，不为某次情节临时制造只对一人有效的例外。
4. 从空间、光线、色彩、物件、服饰与环境行为中选择少量相互支持的视觉特征。特征要能在具体场景中反复辨认，不只写“高级、电影感、氛围感”。
5. 让视觉表达服务人物与冲突：不同空间可以体现权力、亲疏或生活秩序，重复物件可以承载关系变化。避免让风格装饰抢走叙事功能。

## 完成标准

世界规则能用于判断人物行动是否成立，视觉识别能指导可观察的场景表达。两者共同服务同一故事，不包含无用途的设定堆积。

## 自检

- 规则是否彼此冲突，或允许人物轻易绕过核心阻力？
- 是否擅自改写了已经明确的原作事实或项目设定？
- 视觉方向是否能够落实到画面，而非只有抽象形容？
- 是否把未给出的制作预算当成了确定限制？

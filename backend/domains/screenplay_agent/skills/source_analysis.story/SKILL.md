# 故事梳理

**核心任务：组织故事的推进关系，说明起始处境经过哪些事件与转折，形成了当前局面。**

## 优先方法

1. **识别持续推动力。**找出人物试图改变的处境、持续的问题、威胁或关系，以及已呈现的阻力与代价。目标发生替换或重新理解时保留变化；群像或片段式叙事可以有多条推进线。

2. **组织关键节点。**围绕一段行动或局势变化，连接原有处境、关键事件、已发生结果与新形成的条件。完整行动可以跨章合并；因果有依据才连接，无因果依据时保留时间、并行或其他明确关系。

3. **辨认转折与阶段。**用目标、可选行动、风险、关系或知情的实质变化识别转折，说明它改变了后续什么条件。阶段依据实际推进划分，不以章节数量、场面大小或固定幕数决定。

## 同时保持清楚

涉及回忆、插叙、倒叙与延迟揭示时，区分事件发生、人物知情和读者获知，保留信息顺序对悬念与选择的作用。

说明支线如何改变人物、信息、条件或形成对照；不必让每条线归入同一冲突。低冲突段落可呈现关系、日常或氛围的积累。作用尚不明确时如实保留。

## 完成检查

让人能理解起点、关键推进、转折与当前局面，并辨认尚未解决及因材料不足无法判断的事项。只组织已有材料，不补情节或设计分集；不以逐章复述、因果猜测或流畅措辞掩盖断点。

# 展开当前人物弧

## 目标

沿已完成的分集结构，说明当前人物从起始状态经过哪些关键选择形成结束状态。

## 方法

1. 用 readScreenplayTaskDependencies 读取人物索引和相关分集结构，锁定当前 characterKey 与 characterName。必要时核对绑定版本的人物设定，保持人物身份和已确定事实一致。
2. 在 startState 中说明故事开始时影响行动的关系、认知、处境或行为策略，在 desire 中说明人物实际想争取或守住的东西。两者应能解释其行动起点。
3. 找出人物面对压力时作出关键选择、承担代价或改变行动方式的分集。turningEpisodes 只引用已经存在的分集 id，按叙事顺序排列并去重。
4. 说明关键选择如何累积成 endState。变化可以是成长、退步、坚持立场或暴露矛盾；结束状态须与实际分集结果相符，不强行为每个人物安排正向成长。
5. 检查人物弧与他人的行动、关系以及主线结果的联系。只展开当前人物，遇到结构未承载的转变时保留其不确定性，不增写不存在的分集事件。

## 完成标准

通过 writeScreenplayCandidatePart 提交当前人物的 character_arcs 候选。contentJson.characterArcs 只含一个条目，保留绑定的 key，填写非空 startState、desire、endState，以及至少一项实际存在的 turningEpisodes；正文说明这些字段之间的行动与因果联系。

## 自检

- 起始状态和欲望能否解释人物已经采取的行动？
- 转折集是否承载了可辨认的选择或变化，而非只有人物出场？
- 结束状态是否由分集中的实际事件形成？
- 是否为解释人物变化而补造了结构中不存在的事件？

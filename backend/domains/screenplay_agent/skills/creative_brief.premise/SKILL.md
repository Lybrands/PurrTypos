# 建立故事前提与核心冲突

## 目标

形成能持续产生行动和选择的故事前提，使核心冲突与核心戏剧问题彼此一致。

## 方法

1. 从已有材料确定故事焦点：谁的处境发生变化，什么事件使其无法继续原有生活，他或他们希望争取什么。群像作品可以有共同处境与相互牵连的目标，不强行压成单一主角。
2. 把背景设定转成可行动的问题。前提应体现具体人物、触发条件、追求和阻力，避免只有世界观介绍或题材口号。
3. 设计或提炼双方能够持续发生作用的矛盾：目标冲突、资源稀缺、关系债务、价值分歧或人物自身的两难。说明为何一次简单行动不能消除阻力。
4. 找到失败、拖延和成功各自可能带来的代价，确认人物有继续行动的理由。以符合设定的利益和关系建立压力，不任意加大灾难规模。
5. 将核心戏剧问题指向观众会持续关心的结果或选择，并检查它能否由当前冲突推动。修订已有前提时保持本次要求保留的人物、设定和核心关系。

## 完成标准

前提说明故事如何开始，核心冲突说明为什么会持续，戏剧问题说明观众期待看到什么得到回答。三者互相支撑，具体而不展开完整剧情。

## 自检

- 人物是在主动追求与选择，还是只被事件连续推着走？
- 冲突是否能靠一次解释或一个无代价选择轻易消失？
- 戏剧问题是否与真正的核心矛盾有关？
- 是否为增强戏剧性而破坏已接受的人物动机或世界规则？

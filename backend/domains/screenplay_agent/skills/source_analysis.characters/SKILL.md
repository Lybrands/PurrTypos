# 人物分析

**核心任务：依据关键行为解释人物的诉求、选择与变化，以及人物之间怎样相互影响。**

## 优先方法

1. **对照目标与行动。**结合人物声称的目标、实际行动、承担的代价和反复保护或回避的事物，判断材料支持哪些诉求。言行矛盾时描述矛盾及可能解释，不强行揭示“真实动机”。

2. **还原选择条件。**围绕关键行为说明人物当时知道什么、受到什么阻力、有哪些已呈现的选择，以及选择造成的后果。结合能力、资源、关系和制度限制解释行为，不虚构可选方案，不用性格标签代替依据。

3. **比较前后表现。**追踪目标、判断、行动方式和关系的变化及触发事件。区分人物自身改变、策略或身份调整，以及信息揭示后读者重新认识人物；允许固守、退缩、恶化和摇摆。

## 关系与叙事作用

说明依赖、利益、权力、情感和知情如何影响选择，又如何被事件改变；信任、知情与依赖分别判断方向。以具体行为说明人物怎样推动事件、制造阻力、传递信息或形成对照。

## 取舍与完成检查

按对关键事件、主要关系和核心体验的影响确定重点，次要人物简述作用。关键结论附对应行为或事件；区分明确事实、有依据的解释与尚不能确定之处，不强加成长弧或未来结局。缺少转变证据时保留阶段状态。

# 摘要归并

**核心任务：压缩重复表述，保住理解故事所需的事件链、状态变化、有效条件和已有分析线索。**

## 归并方法

1. **先判同一性。**人物、地点、组织、物件和事件只有依据充分才合并。区分重复转述、不同视角、后续认知修正，以及相似但不同的行动；名称或描述相近不能单独证明相同。

2. **再保存变化过程。**重复事实保留完整表述，变化则保留起始状态、关键转变与当前状态。串联有依据的条件、行动和已发生后果，留下解释选择所需的中间状态；区分当时所信与后来所知。

3. **最后按损失大小压缩。**先删重复修辞和同义表述，再简化不影响理解的细节。优先保留关键因果、人物变化、规则的限制与例外、未解事项，以及已有主题和改编风险信号及其具体依据；不平均分配章节篇幅。

## 取舍与边界

信息冲突先核对时间、条件、视角和认知变化；无法解释时并存保留，不擅定真相。事实、推测和传闻保持原有归属与确定程度，重复转述不增加证据强度。

只归并已提供的摘要，不补充新事实或新的主题、改编结论。未记录不等于未发生；未再提及不等于已解决。保留因果缺口、部分解决与仍未知之处，不将当前状态扩展为全书结局。

## 完成检查

对照输入核查：关键转变、必要条件或信号依据是否被删掉，历史状态是否被覆盖，不确定信息是否被改成确认事实。

# 主题提炼

**核心任务：提出材料支持的核心问题或体验，说明故事如何呈现它，以及这种解释成立到什么程度。**

## 提炼与检验

1. **从叙事现象提出解释。**观察关键或反复出现的处境、选择、关系、代价、对照与意象，把“亲情、成长、孤独”等标签具体化为故事在呈现什么问题或体验；不强求都归结为道德两难。

2. **用具体表现支撑。**联系人物行动及后果、关系变化、处境对照或意象的叙事作用，说明它们如何支持解释。人物宣言、结果奖惩、词语重复均不能单独证明作品立场；同一信号的重复转述只算同一依据。

3. **用反例限定结论。**检查相反选择、不同结果、反讽和不可靠陈述。遇到不能解释的材料，缩小范围、调整表述或保留并存立场；关键反例和开放性不为结论整齐而删去。

## 主次与表达

按主题与主要冲突、核心关系、关键变化或核心体验的联系判断主次，同时看证据是否具体、解释是否有区分度。覆盖面广但空泛的说法不自动成为主主题；局部或单一信号作有限判断，不凑数量。

## 完成检查

每项主题说明核心问题或体验、具体依据、解释及其范围；有重要反例或未明之处时保留。只依据当前材料，不臆测作者意图。只有题材标签或证据不足时，保留为候选信号，允许暂无稳定主题。

# 设计核心人物

## 目标

建立能共同驱动核心冲突、具有不同选择方式的核心人物组合。

## 方法

1. 依据故事前提判断需要哪些人物功能：推动目标、形成阻力、承载代价、改变关系或提供另一种价值选择。优先保留不可替代的功能，不按热闹程度增加人物。
2. 为每个人物确定具体欲望、主要阻力和当前行为策略。欲望应能转成行动，阻力应与故事冲突发生关系，而不是与主线无关的背景缺陷。
3. 用人物在压力下如何选择来形成区别，包括会保护什么、愿意牺牲什么、通常怎样争取结果。减少只有职业、外貌或性格形容词不同的同质人物。
4. 检查人物之间的关系能否产生相互影响：一人的选择应改变另一人的处境，合作与冲突应有利益、情感或价值依据。
5. 给出与故事主题相符的变化方向，可以成长、退步、守住立场或暴露矛盾。变化必须有可被后续事件考验的起点，不要求所有人物都完成正向成长。
6. 改编时以原作人物的关键动机与关系功能为依据；原创时围绕前提形成一致的人物组合。修订时保持明确要求保留的人物身份与关系。

## 完成标准

每个人物都能说明为何需要存在、想争取什么、为何受阻以及可能如何变化；人物组合能自然产生故事，而非独立的人物简介集合。

## 自检

- 去掉某个人物后是否几乎不影响故事，他的功能是否与别人重复？
- 人物欲望是否足够具体，能驱动当前故事中的行动？
- 主要关系是否具有相互作用，而非只围绕主角单向服务？
- 变化方向是否由人物自身矛盾产生，而非贴上通用成长结论？

# 划分分集索引

## 目标

确定与项目形式和素材容量相符的分集边界，让每集具有不同且必要的叙事推进。

## 方法

1. 从既定创作简报和主线材料确认整体范围、用户指定的集数以及形式要求。用户已经确定的数量应被遵守；未确定时根据独立戏剧单元和表达容量选择，不将原作章节数直接换成集数。
2. 先寻找可以形成一集主要行动的目标、困境或关系变化，再安排素材归属。完整的行动链可以跨越原作章节，一章也可能包含多个不同单元。
3. 为每集用简洁概要说明本集处理的核心问题、主要推进和叙事边界。边界要能区分相邻两集，避免多个概要只是同一冲突的近义改写。
4. 检查相邻集的承接：上集留下的变化为下集提供行动条件；主线推进与必要支线相互作用，避免为分集而制造没有后果的插曲。
5. 对改编材料只关联确实作为依据的章节。标题应区分本集的核心事件或体验，概要保留后续展开空间，不在索引阶段写场景和对白。

## 完成标准

每集都有清楚的叙事职责，整体覆盖预期故事范围，前后边界可用于逐集展开。分集数量有项目或内容依据，而非来自机械均分。

## 自检

- 是否出现只有铺垫没有有效变化，或只重复上集信息的一集？
- 某集是否塞入过多互不相干的任务，另一集却几乎没有内容？
- 相邻集是否重复消耗同一事件或遗漏必要因果？
- 改编依据是否来自真实材料，原创项目是否被错误添加了来源章节？

# 当前场景写作

## 目标

把已绑定的场景计划写成可表演、可拍摄的完整场景，使人物行动产生明确变化，并与前后场连续衔接。

## 方法

1. 先确认人物进入本场时的目标、位置、已知信息、关系状态和可用资源。这些条件来自已完成场景及绑定材料，不在开场重置。
2. 让人物通过具体行动争取本场目标，并让人物、环境、规则或时间压力形成实际阻力。冲突应迫使人物选择，不能只靠对白解释。
3. 按行动、反应和新条件组织推进。每个主要节拍应改变信息、力量、关系或下一步选择；在场景计划规定的转折形成后结束。
4. 行动描写只写镜头与表演能够呈现的内容。对白服务于争取、试探、隐瞒、施压或关系变化，并保持人物各自的表达方式。
5. 核对名称、称谓、时空、人物知情范围、物件状态和世界规则。需要改变既有状态时，通过本场可见的行动与后果完成。

## 完成标准

场景目标、阻力和转折均已落实，结束状态由本场行动产生，并为下一场提供清楚的新条件。

## 自检

- 人物是否在采取行动，而不是轮流说明剧情？
- 转折是否改变了局面或人物之后的选择？
- 是否出现人物提前知情、状态跳变或无依据的新设定？
- 删除任一段后若不影响行动与变化，该段是否仍有必要？

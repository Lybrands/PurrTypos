# 创建写作 Skill

把输入中的写法观察整理为一份可以脱离原作独立使用的写作 Skill。它是一个文件包，不是编号清单，也不是单个分析报告。

根目录必须包含 `SKILL.md`。在入口中说明 Skill 的用途、适用时机以及何时需要读取辅助文件。只有内容确实需要按场景或主题分开读取时才建立目录和辅助 Markdown/TXT 文件；不要为了显得完整而机械拆分。

写清楚“在怎样的创作需要下，可以怎样处理”，保留选择空间，不把原作中的局部表现硬化为普遍规则。不要复述原作人物、剧情或原句，也不要把分析证据写入正文。证据关联由宿主独立保存。

提交完整文件集合。文件之间的相对链接必须指向实际存在的文件。`SKILL.md` 的 YAML 头部除简洁准确的 `name` 与 `description` 外，还要包含 `metadata.retrieval`，让创作 Agent 能在不读取正文的情况下判断是否应使用这个 Skill。检索元数据描述可迁移的创作意图、适用情境、目标、关键词和必要的排除条件；不要包含原作名称、人物名、情节、原句或证据编号。

需要判断内容组织方式时，读取 [写作 Skill 组织原则](references/writing-skill-contract.md)。

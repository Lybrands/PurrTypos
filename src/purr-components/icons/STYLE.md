# Purr Icon Style

Purr Icons 采用 **Purr Softline（柔线）** 风格：温和、清晰、轻量，带有适度的圆润感，但不做卡通化。图标首先服务于快速识别，其次才是装饰性。

## 视觉原则

1. **识别优先**：先保留对象最典型的结构，让用户在没有文字时也能一眼识别；抽象不能牺牲语义。
2. **柔和几何**：使用规整几何骨架和圆角转折，避免尖锐、机械或过度拟物。
3. **安静克制**：一个图标只表达一个核心动作，不用虚线、阴影和装饰纹理制造复杂度。
4. **光学校正**：不机械追求数学居中；箭头、播放符号和非对称物体应以视觉重量居中。
5. **语义独立**：不能因为外形接近就复用图标；书籍、阅读、大纲、导入、导出等概念必须有各自的识别轮廓。

## 画布与线条

- 统一使用 `24 × 24` 画布。
- 常规安全区为 `3–21`；圆形和方向性轮廓最多可延伸至 `2.5–21.5`。
- 默认描边为 `1.75`，使用 `round` 线帽和 `round` 转角。
- 同一图标不混用多种描边粗细。
- 小圆角使用 `1.5`，常规容器使用 `2.5`，大面积卡片轮廓最多使用 `3`。
- 图标继承 `currentColor`，业务层不得修改 SVG 内部颜色。

## 结构与细节

- 常规图标最多保留三层信息：外轮廓、关键结构、一个识别细节。
- 内部线条之间建议至少保留 `1.5` 个画布单位。
- 小于 `2.5` 个画布单位的圆点可以实心显示，例如状态点、列表点和机器人眼睛。
- 默认使用线性图标；整块填充只用于“激活、停止、固定”等明确状态。
- 禁止使用虚线轮廓、阴影、渐变或无语义的透明装饰。
- 圆形、方形容器只有在语义需要时才出现，例如“完成状态”或“停止按钮”，不为统一外观额外套框。

## 尺寸与使用

| 场景 | 建议尺寸 |
| --- | --- |
| 紧凑输入框、步骤状态 | 14–16px |
| 普通按钮、列表操作 | 16–18px |
| 导航、工具栏 | 18–20px |
| 首页入口、空状态 | 22–24px |
| 独立展示 | 28–32px |

- 图标尺寸由 `size` 或外层 `font-size` 控制。
- 12–14px 只用于 `CheckIcon`、`CloseIcon`、箭头和 Chevron 等单层符号；对象型、容器型和复合图标不得小于 16px。
- 小型按钮中的常规图标统一为 16px，不能跟随 12px 的按钮文字一起缩小。
- 图标与文字并排时，以文字的视觉中线对齐。
- 纯图标按钮必须由按钮提供可访问名称；有独立含义的图标可使用 `title` 或 `aria-label`。

## 命名与实现

- 使用 `BookIcon`、`ArrowLeftIcon` 这样的语义名称。
- 不使用 `Outlined`、`Filled` 等第三方库命名；状态变体应表达真实语义。
- 成对动作必须共享结构并明确表现方向，例如导入箭头向内、导出箭头向外。
- 所有常规图标通过 `createPurrIcon` 创建。
- 需要动态路径的图标使用 `PurrIcon` 画布，不单独创建 `<svg>`。
- 业务代码统一从 `@/purr-components` 引入，不访问图标内部文件。

## 近似语义边界

- `AiChatIcon` 只表示“发起 / 进入 AI 讨论”，用星标气泡；`MessageIcon` 表示普通会话。
- 对话、版本、设定、大纲和 diff 等所有历史记录入口统一使用 `HistoryIcon`；归档、回滚和等待状态不得借用它。
- `ReadIcon` 表示当前书籍或阅读对象；单个章节使用 `FileTextIcon`；正在编辑的小说正文使用双页稿件形态的 `ManuscriptIcon`。
- 复制章节标题使用一大一小两个标题字形组成的 `CopyTitleIcon`；普通文本复制继续使用重叠页面形态的 `CopyIcon`。
- `OutlineIcon` 用嵌套编号表示卷大纲和章节大纲；全书总纲使用核心统领多个篇章节点的 `MasterOutlineIcon`。
- 小说设定的统一入口使用人物与世界组合的 `StorySettingIcon`；具体人物页继续使用 `TeamIcon`。
- 记忆与伏笔使用脑形与伏笔标记组合的 `StoryMemoryIcon`，不借用临时灵感的 `BulbIcon`。
- AI 输入区选择并注入四层设定 / 伏笔时使用多个信息源汇入当前上下文的 `StoryContextIcon`，不借用小说设定或记忆管理入口的图标。
- `DashboardIcon` 表示故事健康与写作统计，不用于普通页面布局或分栏。

## 新图标验收

- 在 16px 和 24px 下均可辨认。
- 与 `BookIcon`、`SearchIcon`、`CheckCircleIcon` 并排时视觉重量接近。
- 没有独立 `viewBox`、描边宽度、线帽或转角定义。
- 移除内部任意一条线后，如果语义不受影响，就应当移除它。

## Variant: 创作资源工作台

### Design stance
把来源和方法都视为需要持续维护、选择和审核的资产，以固定双栏工作台承载高频操作。

### Key choices
- Layout: 统一面包屑页头、资源切换栏、左侧列表和右侧详情/编辑区。
- Typography: 延续 PurrTypos 的温暖纸张感和紧凑标题体系。
- Color: 现有暖灰底色、纸白表面与玫红强调色。
- Interaction: 可切换方法/来源；新建方法使用项目内弹窗并选择引导或空白创建。

### Trade-offs
- Strong at: 状态密度、编辑效率、长列表和分析任务管理。
- Weak at: 初次进入时工具感稍强，需要良好的空状态引导。

### Best for
- 会频繁维护方法、版本和来源分析的长期创作者。

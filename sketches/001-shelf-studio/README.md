## Variant: 书架工作室

### Design stance
把写作方法和小说来源都呈现为可辨认、可浏览的“创作藏品”，延续书架入口的情绪与视觉隐喻。

### Key choices
- Layout: 方法使用紧凑索引卡网格与独立详情条，来源使用书脊卡片和右侧检查器。
- Typography: 标题使用偏编辑感的衬线字体，正文保持系统字体。
- Color: 保留暖纸色和玫红，并通过卡片顶部色条与来源书脊增强辨识度。
- Interaction: 可切换方法、方案和来源；方法/方案分别使用项目内创建弹窗，选中卡片后在独立详情区查看正文摘要或准确版本栈。

### Trade-offs
- Strong at: 与书架风格一致、卡片信息量与尺寸匹配、空状态自然。
- Weak at: 方法很多时扫描效率仍低于列表；真正编辑仍需要进入详情页。

### Best for
- 方法数量不大、重视视觉归类和书架整体一致性的创作者。
